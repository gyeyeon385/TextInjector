# TextInjector icon

The icon combines a text insertion cursor, a rightward arrow and a keycap on a blue-teal tile. It was generated with the built-in imagegen tool and converted to macOS ICNS sizes using `sips` and `iconutil`.

- Source: `AppIcon.png` (1254 × 1254, RGBA)
- Packaged asset: `../Resources/AppIcon.icns`
- Regenerate icon sizes: `bash scripts/build-icon.sh`
- License: the repository's MIT license applies to these project assets.

## Generation prompt

Use case: logo-brand. Production macOS app icon for TextInjector. A sculpted light keycap bearing a bold text insertion cursor with a compact rightward arrow integrated into the central symbol. Restrained depth, frosted highlights, clear silhouette at 32px. Centered rounded-square blue-teal tile, transparent outside, no lettering, no app name, no third-party logo or watermark. One icon only.
